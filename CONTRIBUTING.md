# Contributing

This is an open working draft. It is meant to be worked on by more than one person.

## The one rule everything else rests on

**Never cite a page you have not opened.**

A page number written from memory looks *more* scholarly than a blank field and is a
fabrication. It is the easiest kind of error to introduce and the hardest to catch,
because nobody notices unless they own the book. The project publishes its count of
verified pages precisely so this cannot be quietly faked.

A blank is honest. A guess is not.

## The other standing rules

1. **Ancient translations control wording. They never vote.** Syriac, Latin, Coptic,
   Armenian, Georgian, Ethiopic and Gothic help establish what the Greek said. None of
   them is an independent witness to what Jesus said.
2. **Where scholarship is contested, store the opposing source beside the claim.**
   35 citations in this project argue against its own conclusions. That is the point,
   not an oversight.
3. **Multiple attestation is not authenticity.** A saying in four sources may be
   everywhere because it was common property, not because he said it.
4. **No confident reconstruction of Aramaic originals.** Published arguments only,
   summarised as such.
5. **When earlier work turns out to be wrong, the correction goes in visibly** — beside
   the original claim, not over the top of it.

## What is most useful right now

**Adopt a citation.** See [adopt.html](https://techhousechurch.com/adopt.html). Pick a
work, find where it makes the listed claim, send the page. Thirty seconds per entry
once the book is open. This is the largest gap in the project and the one part that
genuinely needs a human with library access.

**Answer a Syriac question.** Twelve open questions need Kiraz, *Comparative Edition of
the Syriac Gospels* (NTTS 21/1–4, Brill 1996).

**Source an objection.** Eight rows in the attribution-risk register are recorded but
unsourced, and score nothing until they are.

**Argue with it.** If something here is wrong, the fix is a source, not an opinion.

## How to send something

Open an issue or a pull request on this repository. Every change is reviewed before it
lands, attributed, and reversible. Nothing merges unreviewed — that discipline is the
only reason any of this is worth reading.

## What this project will not do

- Claim to recover Jesus' exact words. See the site's opening statement.
- Publish full copyrighted text or proprietary critical apparatus.
- Present a ranking as a verdict. The ranking measures attestation, not certainty.
